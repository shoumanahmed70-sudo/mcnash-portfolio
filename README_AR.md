# MCNASH — Photography & Films

موقع أسود وذهبي بهوية وصورة MCNASH، ومعرض صور وأفلام وتصنيفات، وعرض مكبر، وتواصل للحجز عبر Instagram. دخول المدير من admin.html، والعملاء يشاهدون دون حساب. الواجهة باللغة الإنجليزية.

## الإعداد مرة واحدة
1. أنشئ مشروع Supabase من https://supabase.com .
2. افتح SQL Editor وشغّل setup.sql مرة واحدة في مشروع جديد.
3. من Authentication > Users أنشئ مستخدم المدير بإيميله وكلمة مروره، ثم انسخ UUID الخاص به.
4. نفّذ السطر الأخير المعلق في setup.sql بعد استبدال YOUR-USER-UUID بالمعرف الصحيح وإزالة --. لا تضف أي مستخدم آخر إلى admins إلا إذا أردت منحه الإدارة.
5. أغلق التسجيل العام من إعدادات Authentication. إنشاء حساب وحده لا يمنح صلاحية إدارة.
6. في config.js أضف رابط مشروع Supabase ومفتاح anon العام أو publishable key. لا تستخدم service_role أو أي مفتاح سري. صلاحيات الكتابة محمية في قاعدة البيانات وسياسات التخزين، وليست بمجرد إخفاء زر الإدارة.
7. فك ZIP وارفع محتويات المجلد إلى مستودع GitHub. من Settings > Pages اختر النشر من الفرع main والجذر. الملف .nojekyll مرفق.
8. افتح رابط الموقع ثم admin.html وسجّل الدخول. أضف الصور والأفلام وعدّل نص المقدمة والنبذة وصورة الواجهة. بعد الحفظ يظهر المحتوى للعملاء عند تحديث الصفحة دون إعادة رفع GitHub.

## ما يمكنك تعديله
- إضافة وحذف أعمال بصور JPG/PNG/WebP أو فيديو MP4، مع عنوان وتصنيف وغلاف للفيلم.
- تعديل المقدمة والنبذة وصورة الواجهة. لتغيير عنوان أو تصنيف عمل حالي احذفه ثم أعد إضافته.
- الحجز الحالي يتم بالتواصل عبر Instagram، وليس نظام مواعيد أو دفع.
- اسم الهوية ورابط Instagram ثابتان في index.html؛ تغييرهما أو تغيير التصميم يحتاج تعديل الملفات.
- الحد المخصص للملف الواحد 40MB. راقب حدود خدمة التخزين في حسابك. الملفات عامة لأن المعرض عام. حذف العمل من القائمة لا يمسح ملفه من التخزين؛ يمكن حذفه يدويًا من Storage لتوفير المساحة.

## حالة التسليم
المشروع مجهز للربط، ولم يتم إنشاء خدمة Supabase أو حساب مدير أو نشره على الإنترنت. لا يوجد باسورد افتراضي أو أسرار مرفقة. فحص تركيب JavaScript وملفات الحزمة ممكن محليًا؛ الدخول والحفظ والرفع والصلاحيات تحتاج اختبارًا بعد الربط بخدمتك الفعلية. المعرض يبدأ فارغًا بدل نسبة صور غير حقيقية للمصور؛ صورة الهوية المرسلة مرفقة كواجهة مؤقتة قابلة للاستبدال.

## تشغيل محلي
شغّل python -m http.server 8000 داخل المجلد ثم افتح http://localhost:8000 . الاتصال بالإنترنت مطلوب لتحميل مكتبة Supabase وخدمة البيانات.
